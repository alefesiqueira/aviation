## 2024-04-23 - Replacing deprecated iframe attributes with Tailwind CSS
**Learning:** Found that legacy iframe attributes (like `frameborder="0"`, `scrolling="no"`, `marginheight="0"`, `marginwidth="0"`) can often create validation warnings and represent an outdated approach. However, because we cannot introduce custom CSS here, replacing them with functionally equivalent utility classes from Tailwind (e.g., `border-none`, `overflow-hidden`, `m-0`) is an excellent way to maintain layout while modernizing markup, ensuring accessibility attributes like `title` can stand out without legacy clutter.
**Action:** Always replace legacy iframe styling attributes with their respective Tailwind CSS counterparts when refactoring HTML widgets in this design system, and pair with clear ARIA or `title` attributes in pt-BR.
